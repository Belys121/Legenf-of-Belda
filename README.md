# Legen of Belda - Warrior Arena Battle Game[WIP]
### Description
Warrior Arena Battle Game is a simple console-based game where players can choose different warriors, each with unique
stats and abilities, to fight against each other in an arena. This game currently runs in the console, but it can be
expanded in the future with a graphical user interface for enhanced gameplay.


### How to Play
1) Choose Your Warrior: At the start, the player selects a warrior from a list of characters, each with unique health
and damage stats.
2) Choose Your Opponent: After selecting your warrior, choose an enemy warrior from the list to battle against.
3) Battle in the Arena: The warriors take turns attacking each other until one of them is defeated. Each attack
has a chance to miss or deal bonus damage, adding an element of chance to the game.
4) Win Condition: The battle continues until one warrior's health reaches zero, at which point the surviving warrior
is declared the winner.

### Available Warriors
- Knight - Higher health and moderate damage.
- Archer - Balanced health with slightly higher damage.
- Death Knight - High damage with good health.
- Paladin - Balanced health and damage.
- Hunter - Higher damage with slightly lower health.
- Rogue - Low health but high damage.
- ... and many more unique characters.

Each character has unique base stats for health and damage, which influences their performance in battle.

### Running the Game
1) Clone the Repository: Clone this repository to your local machine. 
2) Run the Game: In your terminal, navigate to the project folder and run:
```
python <filename>.py
```
 Replace <filename>.py with the name of the Python file containing the game code.

3) Start Playing: Follow the prompts in the terminal to choose your warrior and start the battle!
